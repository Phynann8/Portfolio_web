# Project Documentation

## 1. Project Overview

This project is a personal portfolio website for Chhun Phynann, a Computer Science student, Software Developer, and Freelancer. The website showcases his skills, projects, experience, and provides contact information. It is designed to be a clean, modern, and responsive single-page application.

**Technologies Used:**

*   **HTML:** The standard markup language for creating the structure of the web page.
*   **CSS:** Used for styling the website, including layout, colors, fonts, and responsive design.
*   **JavaScript:** Adds interactivity to the website, such as dynamically updating the copyright year.

## 2. File Structure

The project is organized into the following files and directories:

*   **`index.html`:** The main HTML file that contains the structure and content of the website.
*   **`style.css`:** The stylesheet that defines the visual presentation of the website.
*   **`script.js`:** Contains the JavaScript code for the website's functionality.
*   **`Resume/`:** A directory containing the resume file.
    *   **`resume.pdf`:** Chhun Phynann's resume in PDF format.

## 3. Current Features

The website currently includes the following sections and features:

*   **Navigation Bar:** A sticky navigation bar that allows users to easily navigate to different sections of the page.
*   **Hero Section:** A welcoming section with a headline and a brief introduction.
*   **About Me:** A section providing a more detailed description of Chhun Phynann's background and passion.
*   **Skills:** A section listing technical skills, including programming languages, web development technologies, and database management.
*   **Projects:** A section to showcase completed projects with descriptions and links to the code and live demos.
*   **Experience:** A section to detail internship and freelance experience.
*   **Contact:** A section with email and phone number for contact.
*   **Footer:** A footer that includes social media links and a dynamically updated copyright year.
*   **Resume:** A link to a downloadable PDF version of the resume.
